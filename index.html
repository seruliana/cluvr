Pets

Register and onboard a new pet profile

Creates a new pet profile in the Corg.ly registry. Generates a unique pet identifier and initializes baseline health and vocal metrics for translation models.

Authorizations:
BearerAuth
Request Body schema: application/json
required

Pet profile creation payload containing identity and demographic details.

pet_name
required
string [ 1 .. 50 ] characters

Given name of the pet.

breed
required
string

Breed of the dog.

age_months
required
integer [ 1 .. 300 ]

Pet age in months.

owner_email
required
string <email>

Email address of the owner.

Responses

Production Server

https://api.corg.ly/v1/pets

Local Prism Mock Server (Sandbox & Testing)

http://127.0.0.1:4010/pets

Upload pet profile picture (Multipart Form Data)

Accepts binary image upload (JPEG/PNG) associated with a pet ID. Validates file resolution, strips EXIF metadata, stores image in secure cloud CDN, and binds URL to the pet record.

Authorizations:
BearerAuth
Request Body schema: multipart/form-data
required

Multipart binary form data with pet ID and photo file.

pet_id
required
string

Unique ID of the pet receiving the new photo.

photo_file
required
string <binary>

Binary photo file (JPEG or PNG, max 10MB).

Responses

Translation

Translate canine vocalization audio to natural human language

Analyzes audio acoustic frequencies, pitch modulation, and duration using Corg.ly's deep learning bark recognition neural network. Returns translated human intent, emotional state, and confidence score.

Authorizations:
BearerAuth
Request Body schema: application/json
required

Audio payload with base64 encoded audio bytes and acoustic metadata.

pet_id
required
string

Pet ID associated with the vocal bark audio.

audio_format
required
string
Enum: "wav" "mp3" "ogg" "flac"

Audio compression encoding format.

sample_rate_hz
required
integer
Enum: 16000 22050 44100 48000

Sampling frequency in Hertz.

audio_base64
required
string

Standard Base64 encoded binary audio payload.

Responses

Production Server

https://api.corg.ly/v1/audio/translate-bark

Local Prism Mock Server (Sandbox & Testing)

http://127.0.0.1:4010/audio/translate-bark

Webhooks

Register a webhook listener endpoint for real-time pet activity events

Subscribes an external HTTPS endpoint to receive asynchronous webhook event notifications such as bark translations, feeding alerts, or health warnings.

Authorizations:
BearerAuth
Request Body schema: application/json
required

Webhook subscription registration payload.

callback_url
required
string <uri>

Secure HTTPS endpoint to which Corg.ly server delivers POST event webhooks.

event_types
required
Array of strings non-empty
Items Enum: "bark.translated" "pet.activity_alert" "pet.health_threshold_exceeded" "pet.photo_updated"

List of subscribed asynchronous event triggers.

secret_token
required
string >= 16 characters

Client-provided secret key used to compute HMAC SHA-256 webhook signatures.

description
string

Human-readable operational purpose of this webhook subscription.

Responses

Production Server

https://api.corg.ly/v1/webhooks/subscribe

Local Prism Mock Server (Sandbox & Testing)

http://127.0.0.1:4010/webhooks/subscribe
